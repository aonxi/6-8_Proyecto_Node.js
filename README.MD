# Proyecto Backend Node.js, Express y PostgreSQL - Módulo 7

## Descripción

Este proyecto corresponde al desarrollo del backend del Módulo 7. En esta etapa se amplió la aplicación desarrollada en el Módulo 6 incorporando persistencia de datos mediante PostgreSQL, modelado de datos con Sequelize ORM, relaciones entre entidades, operaciones CRUD, búsquedas dinámicas, transacciones y manejo centralizado de errores.

El proyecto utiliza una arquitectura modular basada en rutas, controladores, servicios, modelos y middlewares.

## Tecnologías utilizadas

- Node.js
- Express
- PostgreSQL
- Sequelize ORM
- JavaScript
- Dotenv
- Nodemon
- pg
- pg-hstore
- Postman para pruebas de la API

## Requisitos

- Node.js 18 o superior
- npm
- PostgreSQL
- Git
